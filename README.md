# 🧠 Memory Visualizer

An interactive **Operating System Memory Management Simulator** that helps visualize core concepts like **Paging (FIFO & LRU), Segmentation, and Virtual Memory (MMU)** through step-by-step execution.

---

## 🚀 Features

* 📌 Paging simulation using **FIFO & LRU algorithms**
* 📌 Segmentation with logical → physical address translation
* 📌 Virtual Memory with MMU simulation
* 📌 Step-by-step visualization of memory operations
* 📌 Clean and interactive UI

---
